# Commit Messages Guide — Vuvoz

## Формат

```
<тип>: <краткое описание (50 символов)>

[опционально: подробное описание]
```

## Типы коммитов

| Тип | Описание |
|-----|----------|
| `feat` | Новая возможность |
| `fix` | Исправление бага |
| `docs` | Изменения в документации |
| `style` | Форматирование, без изменения логики |
| `refactor` | Рефакторинг кода |
| `test` | Добавление/изменение тестов |
| `chore` | Служебные изменения (deps, config) |

## Примеры

```
feat: добавлена публичная главная страница с лентой новостей
```

```
fix: исправлена проверка прав для admin_client в тестах News API
```

```
docs: обновлён DEPLOYMENT.md с Nginx и Gunicorn
```

```
test: добавлены тесты для NewsArticle API
```

```
chore: обновлён .gitignore
```
