# Чек-лист проверки интерфейса

Перед проверкой загрузите тестовые данные (из **корня проекта**). Для каталога товаров за баллы: `python scripts/create_bonus_products.py`.

```bash
# Предпочтительно: скрипт сам подставляет путь к проекту
python scripts/load_test_data.py
```

Через shell (если нужен явный encoding для русских названий):
```bash
python manage.py shell -c "exec(open('scripts/load_test_data.py', encoding='utf-8').read()); run()"
```

Очистить базу (оставить только админ), затем снова загрузить данные:
```bash
python scripts/clear_db.py
# затем
python scripts/load_test_data.py
```

Учётные данные после загрузки:
- **Админ:** создаётся отдельно (например через `setup_dev_data.py`) или уже есть в БД — логин/пароль по вашему окружению
- **Компании:** company1@test.com, company2@test.com / test123
- **Организации:** 20 организаций (логин = email, например school01@test.com, office01@test.com; пароль = test123)

---

## 1. Общедоступная главная

- [ ] Открывается главная страница (Вывоз макулатуры).
- [ ] Шапка с отступами (padding), не прижата к краям.
- [ ] Блоки «О сервисе», «Новости», «Контакты» отображаются.
- [ ] Переход по якорям (Главная, О сервисе, Новости, Контакты) работает.
- [ ] Кнопка «Войти» ведёт на страницу входа.
- [ ] Открытие новости и кнопка «Назад» работают.

---

## 2. Вход и роли

- [ ] Вход под admin → редирект в админ-панель.
- [ ] Вход под company1@test.com → панель компании.
- [ ] Вход под одной из организаций (email из тестовых данных) → панель организации.
- [ ] Выход работает для каждой роли.

---

## 3. Панель администратора

- [ ] Шапка с отступами (px-4 py-2), карточки с скруглением и тенью.
- [ ] **Цены:** список, добавление, редактирование, удаление записи.
- [ ] **Новости:** список, создание, редактирование, удаление.
- [ ] **Компании:** список, просмотр карточки, добавление, редактирование, удаление.
- [ ] **Организации:** список, поиск по названию, просмотр, добавление, редактирование, удаление.
- [ ] **Заявки:** список, фильтр по статусу и организации, просмотр карточки заявки.
- [ ] **Товары (баллы):** список, добавление, редактирование, удаление; загрузка фото через Django admin (см. README).
- [ ] **Заказы за баллы:** список заказов, просмотр корзины, смена статуса (принят / доставлен).
- [ ] Лимиты веса: в форме заявки от организации проверка мин/макс веса (настроено в админке/фикстурах).

---

## 4. Панель компании

- [ ] Шапка с отступами, карточки оформлены единообразно.
- [ ] **Обзор:** информация о компании, блок «Мои организации», текущие и завершённые заявки.
- [ ] **Статистика:** переключение периода, данные отображаются.
- [ ] **Организации:** список, добавление, просмотр, редактирование, удаление.
- [ ] **Заявки / Завершённые:** списки заявок, смена статуса (при необходимости).
- [ ] Модальные окна (карточка организации, заявки, удаление) открываются и закрываются.

---

## 5. Панель организации

- [ ] Шапка с отступами, карточки с скруглением.
- [ ] Блок профиля организации (контакт, телефон) и кнопка «Изменить контактные данные».
- [ ] Форма «Новый запрос на вывоз»: выбор типов макулатуры и веса, отправка.
- [ ] Валидация веса: сообщение при весе ниже мин или выше макс (из настроек лимитов).
- [ ] Вкладки «Текущие заявки» и «Завершённые заявки»: данные отображаются после загрузки тестовых данных.
- [ ] **Баллы:** отображаются баланс, история (начисления и траты).
- [ ] **Каталог товаров за баллы:** карточки товаров (фото, если загружены), кнопка «В заказ», оформление заказа.

---

## 6. Общее

- [ ] Нет консольных ошибок (F12) на основных сценариях.
- [ ] Адаптивность: при сужении окна элементы не наезжают друг на друга, таблицы/карточки ведут себя предсказуемо.

После прохождения чек-листа интерфейс можно считать проверенным.
