# Project Status — Vuvoz

## Текущий статус

- **Версия**: 1.0
- **Тесты**: 21 тест, все проходят (API, лимиты веса, валидация заявок, профиль учреждения)
- **Backend**: Django 4.2+, DRF, JWT, PostgreSQL/SQLite
- **Frontend**: Vue 3, Vuetify 3, TypeScript, Vite

## Последние изменения (для релиза / проверки на другой машине)

- **Тесты**: добавлены тесты лимитов веса (GET `/api/weight-limits/`, валидация мин/макс при создании заявки), тесты обновления профиля учреждения (контакт, телефон). Всего 21 тест. Запуск: `pytest tests/ -v`.
- **UI**: отступы шапки (px-4 py-2) и скругление карточек (rounded-lg, elevation-1) во всех дашбордах и на главной/новостях.
- **Скрипты**:
  - `scripts/load_test_data.py` — 2 компании, 20 организаций (школы, офисы, магазины, производство) с русскими названиями, по 1 новой и 1 завершённой заявке на организацию (40 заявок). Запуск из корня: `python scripts/load_test_data.py`. Файл в UTF-8.
  - `scripts/clear_db.py` — очистка БД с сохранением только суперпользователей (админ). Запуск: `python scripts/clear_db.py`.
  - `scripts/generate_stats_data.py` — создаёт ~60 заявок для проверки статистики (разные даты, типы макулатуры, статусы). Требуется `load_test_data.py`. Запуск: `python scripts/generate_stats_data.py`.
- **Зелёные баллы**: каталог товаров (Product), заказы (PointsOrder), история в `/api/me/points/`; админ управляет товарами и статусами заказов; учреждения заказывают за баллы. API: `/api/products/`, `/api/points-orders/`.
- **Фото товаров**: `Product.image` (ImageField), `image_url` в API; фото в `media/products/`; Vite проксирует `/media` и `/static` на Django.
- **Главная страница**: редизайн в стиле Ubirator, кнопка «Регистрация» с формой (имя, отчество, учреждение, адрес, телефон). Заявки на регистрацию: модель `InstitutionRegistrationRequest`, API `POST /api/registration-requests/` (публично), список в админке.
- **Статистика (админ)**: вкладка «Статистика» с 4 отчётами (объём по материалам, топ организаций, заявки по статусам, динамика). Фильтры: период (1 неделя … 1 год, свой), основа (`created` / `completed`). Переключение таблица/график. API `GET /api/stats/admin/`. Логика: [docs/STATISTICS_LOGIC.md](docs/STATISTICS_LOGIC.md).
- **Документация**: README, API_DOCS, TROUBLESHOOTING, [docs/INTERFACE_TEST_CHECKLIST.md](docs/INTERFACE_TEST_CHECKLIST.md), [docs/STATISTICS_LOGIC.md](docs/STATISTICS_LOGIC.md).

## Future Ideas / Roadmap

Ниже — идеи для развития Vuvoz, которые сделают сервис ещё удобнее и конкурентоспособнее.

### Интеграции

- **Yandex.Maps** — отображение адресов учреждений и маршрутов вывоза на карте. Компании смогут планировать выезды, видеть территориальное распределение заявок, оптимизировать логистику.
- **Telegram-бот** — полноценный канал для учреждений: создание и отслеживание заявок, уведомления о статусах, просмотр баланса зелёных баллов, каталог товаров. Всё прямо в Telegram, без необходимости заходить в веб-интерфейс.

### Пользовательский опыт

- **Email-уведомления** — письма при смене статуса заявки, напоминания о вывозе, дайджесты по баллам.
- **PWA / мобильное приложение** — офлайн-режим, пуш-уведомления, установка на домашний экран.
- **Мультиязычность (en)** — интерфейс и документация на английском для международной аудитории.

### Аналитика и отчётность

- **Экспорт заявок** — в Excel/PDF по выбранному периоду, организациям или статусам.
- **Дашборды и визуализация** — графики, heat maps, прогнозы по объёмам вывоза.
- **API для интеграций** — webhook при завершении заявки, публичные endpoints для внешних систем (ERP, учётные системы).

### Бизнес-функции

- **Договоры и акты** — генерация документов (договор, акт приёма-передачи) из шаблонов.
- **Автоматическое начисление баллов** — мгновенное зачисление после подтверждения вывоза без ручного подтверждения админом.
- **Реферальная программа** — бонусы за приглашение новых учреждений.

### Безопасность и инфраструктура

- **2FA (двухфакторная аутентификация)** — для администраторов и компаний.
- **Аудит логов** — кто, когда и что изменил (заявки, цены, организации).
- **Rate limiting и защита от brute-force** — DRF throttling для API и логина.
